# 常见问题 FAQ

## 📡 通信相关

### Q1: 通信距离只有 50-100 米，如何提升？

**A:** 通信距离受多种因素影响：

**检查清单：**
1. ✅ 确认 LR 模式已启用（串口输入 `w` 查看）
2. ✅ 确认使用外置天线（5dBi 或更高）
3. ✅ 确认天线正确连接到 U.FL 接口
4. ✅ 测试不同信道（1、6、11、13）
5. ✅ 避开 WiFi 密集区域

**优化方案：**
- 更换 9dBi 全向天线（提升 60%）
- 使用 12dBi 定向天线（提升 100%，需对准）
- 提高天线安装高度

**理论距离：**
- 城市环境：150-200 米
- 空旷环境：300-500 米

---

### Q2: 出现"嗡嗡嗡"断续声音？

**A:** 这是丢包导致的音频断续。

**解决方法：**
1. 缩短通信距离
2. 更换信道（避开干扰）
3. 减少同时通话设备数量
4. 检查天线连接

---

### Q3: 所有设备必须使用相同信道吗？

**A:** 是的！

ESP-NOW 协议要求所有通信设备使用相同的 WiFi 信道。

**配置方法：**
```cpp
#define WIFI_CHANNEL 1  // 所有设备改为相同值
```

---

### Q4: 支持多少设备同时通信？

**A:** 理论支持 10 设备，实际建议 5-8 设备。

**原因：**
- 带宽限制（1Mbps 共享）
- 信道拥塞
- 音频混音质量

---

## 🎙️ 音频相关

### Q5: 音质不好，有杂音？

**A:** 可能的原因和解决方法：

**1. 麦克风增益过高**
```cpp
#define AUDIO_GAIN 0.8f  // 降低增益
```

**2. VAD 阈值过低**
```cpp
#define VAD_ENERGY_THRESHOLD 2500  // 提高阈值
```

**3. 硬件问题**
- 检查麦克风连接
- 检查电源稳定性
- 远离电磁干扰源

---

### Q6: 延迟太高，如何降低？

**A:** 当前配置已经是最低延迟（<50ms）。

**检查项：**
- 确认使用 iLBC-20ms（不是 30ms）
- 确认 LR 模式已启用
- 减少 DMA 缓冲区数量（不推荐）

**注意：** 进一步降低延迟会影响稳定性。

---

### Q7: 自听音有回声？

**A:** 这是正常现象。

**解决方法：**
- 按下 EC11 编码器按键关闭自听音
- 或降低自听音音量（代码中修改）

---

## 🔧 硬件相关

### Q8: 必须使用 ESP32-S3-WROOM-1U 吗？

**A:** 不是必须，但强烈推荐。

**兼容型号：**
- ✅ ESP32-S3-WROOM-1U（推荐，支持外置天线）
- ✅ ESP32-S3-WROOM-1（仅板载天线，距离较短）
- ✅ ESP32-S3-DevKitC-1（开发板）

**要求：**
- 至少 8MB Flash
- 支持 I2S 接口
- 不需要 PSRAM

---

### Q9: 可以使用板载天线吗？

**A:** 可以，但距离会大幅降低。

**距离对比：**
- 板载 PCB 天线：50-100 米
- 5dBi 外置天线：150-200 米
- 9dBi 外置天线：250-350 米

---

### Q10: 必须使用 PDM 麦克风吗？

**A:** 不是必须，但推荐使用数字麦克风。

**兼容方案：**
- ✅ PDM 数字麦克风（推荐，抗干扰）
- ✅ I2S MEMS 麦克风（需修改代码）
- ⚠️ 模拟麦克风 + ADC（不推荐，音质差）

---

## ⚙️ 配置相关

### Q11: 如何修改频道数量？

**A:** 频道数量由 ES16 开关决定（0-15 共 16 个频道）。

如果使用其他开关：
```cpp
// 修改频道掩码
#define CHANNEL_MASK 0xF000  // 4位=16频道
```

---

### Q12: 可以修改采样率吗？

**A:** 不建议修改。

**原因：**
- iLBC 编解码器固定 8kHz
- 修改采样率需要重新配置编解码器
- 可能导致兼容性问题

---

### Q13: 如何禁用 VAD，改为纯 PTT 模式？

**A:** 修改代码：

```cpp
// 在 loop() 函数中
// 注释掉 VAD 检测部分
// if (vadState == VAD_STATE_VOICE_ACTIVE) { ... }

// 只保留 PTT 按键检测
if (digitalRead(PTT_PIN) == LOW) {
    // 发送音频
}
```

## 🐛 故障排除

### Q14: 编译失败，提示找不到库？

**A:** 检查库文件：

```bash
# 查看 lib 目录
ls lib/

# 应该包含：
# - arduino-libilbc-main
# - arduino-audio-tools-1.1.2
```

如果缺少，重新克隆项目。

---

### Q15: 上传失败，无法连接设备？

**A:** 检查串口连接：

```bash
# 查看可用串口
platformio device list

# 指定串口上传
platformio run --target upload --upload-port COM3
```

---

### Q16: 设备重启后配置丢失？

**A:** 当前版本不支持配置保存。

**临时方案：**
- 修改代码中的默认值
- 重新编译上传

**未来版本：**
- 将添加 NVS 配置保存功能
